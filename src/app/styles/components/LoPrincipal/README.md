# Bloque: Lo principal

### Descripción
Bloque informativo que destaca los pilares o características esenciales del proyecto DGR SPARK.

### Archivos
- `index.jsx`: componente React.
- `loPrincipal.module.css`: estilos locales.
- `data.json`: datos dinámicos del bloque.
- `assets/`: íconos o imágenes.

### Cómo usar
```jsx
import LoPrincipal from "@/components/LoPrincipal";

export default function Home() {
  return (
    <>
      <LoPrincipal />
    </>
  );
}
